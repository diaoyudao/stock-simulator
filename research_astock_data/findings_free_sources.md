# 免费 A 股数据源调研 (2025-2026)

调研日期：2026-05-19

---

## 1. 新浪财经 API (Sina Finance)

### 可用性：部分可用，不稳定，非官方

新浪从未公开提供正式的股票数据 API。现有接口均为逆向其前端 JavaScript 获得的内部地址，**无官方文档、无 SLA、随时可能被封**。

#### 已知可用端点

| 端点 | 说明 |
|------|------|
| `https://hq.sinajs.cn/list=sh600519,sz000001` | 实时行情（最新价、买卖五档、成交量等） |
| `https://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData?symbol=sh600519&scale=240&ma=no&datalen=250` | 日K线数据 |

#### 数据类型

- **实时行情**：最新价、今开、昨收、买卖五档、成交量/额、涨跌 — 可用
- **日K/周K/月K**：可用（月K不支持，需从日K聚合）
- **分时/盘口/资金流向/财务/资讯**：新浪本身不提供，需 AKShare 或其他源

#### 限制与风险

- 无官方文档，接口随时可能变更或关闭
- 调用频率有限制，频繁请求会触发反爬
- 数据覆盖面窄，缺乏基本面、技术指标数据
- 2025 年新浪财经 APP 端新增"喜娜 AI 助手"，但未以 API 形式对外开放
- 多位开发者反馈新浪部分接口已作废

#### 结论

**可作为实时行情主数据源，但必须有降级方案。** 不建议作为唯一依赖。

## 2. 腾讯财经 API (Tencent Finance)

### 可用性：可用，稳定性优于新浪，同样非官方

#### 核心端点

| 端点 | 说明 |
|------|------|
| `https://qt.gtimg.cn/q=sh600519,sz000001` | 实时行情（~分隔文本，支持批量） |
| `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,day,,,320,qfq` | 日K线（前复权） |
| `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,week,,,52,qfq` | 周K线（可用于52周高低） |
| `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,month,,,60,qfq` | 月K线 |

#### 实时行情字段（~分隔索引）

| 索引 | 字段 | 索引 | 字段 |
|------|------|------|------|
| 1 | 股票名称 | 36 | 成交额（万） |
| 3 | 当前价格 | 37 | 换手率 |
| 4 | 昨收价 | 38 | 市盈率（动态） |
| 5 | 今开价 | 41 | 当日最高 |
| 6 | 成交量（手） | 42 | 当日最低 |
| 9 | 买一价 | 43 | 价格变动 |
| 44 | 涨跌幅(%) | — | — |

#### 量比与52周高低

- **量比**：腾讯接口不直接提供，需自行计算（当日累计成交量 / 过去5日同时段平均成交量）
- **52周高低**：通过周K线接口获取近52周数据，取最大/最小值

#### 数据类型

- **实时行情**：最新价、涨跌幅、成交量/额、换手率、市盈率、买卖盘 — 可用
- **日K/周K/月K**：可用，支持前复权/后复权
- **分时/盘口/资金流向/财务/资讯**：不提供

#### 限制

- 无官方文档，接口可能变更
- 建议请求间隔 >= 3 秒，避免 IP 被封
- 行情约延迟 15 秒，非 Level-2 逐笔数据
- 量比需自行计算，精度依赖历史数据

#### 结论

**作为新浪的补充数据源，稳定性略好。** 本项目当前用于补充量比和52周高低，这一用法合理。

## 3. AKShare

### 可用性：接口频繁变动，_em 后缀接口依赖东方财富，易断裂

AKShare 是开源 Python 金融数据库，接口丰富但**依赖爬虫**，源网站变更就会导致接口失效。

#### 各接口状态评估

| 接口 | 数据源 | 当前状态 | 风险等级 | 说明 |
|------|--------|---------|---------|------|
| `stock_zh_a_spot_em` | 东方财富 | 可用但易断 | 高 | 东方财富频繁改 API 路径/字段名，导致返回空 DataFrame 或解析错误 |
| `stock_intraday_em` | 东方财富 | 可用但易断 | 高 | 分时数据 URL/参数/JSON 结构经常变化 |
| `stock_bid_ask_em` | 东方财富 | 可用但易断 | 高 | 五档盘口，同受东方财富反爬影响 |
| `stock_individual_fund_flow` | 东方财富 | 可用但易断 | 高 | 资金流向，依赖特定 API 路径 |
| `stock_zh_a_minute` | 东方财富 | 可用但易断 | 高 | 分钟K线，同源风险 |
| `stock_financial_abstract_ths` | 同花顺 | 中等稳定 | 中 | 同花顺页面结构相对稳定，但仍可能变化 |
| `stock_news_em` | 东方财富 | 经常损坏 | 极高 | 资讯接口最不稳定，源站反爬最严格 |

#### 常见故障模式

1. **HTTP 403/404**：东方财富更新 API 路径
2. **数据解析错误**：响应字段名变更
3. **空 DataFrame**：API 返回新格式，解析器未适配
4. **频率限制**：反爬检测加强，请求被拦截

#### 应对策略

- **保持 AKShare 版本最新**：`pip install akshare --upgrade`，维护者通常在数天内修复
- **不要依赖单一 AKShare 接口**：对关键数据准备直接 HTTP 请求的降级方案
- **直接调用东方财富 API**：绕过 AKShare 包装，自行维护请求参数（见第6节）
- **添加请求间隔和异常处理**：避免连续高频调用

#### 结论

**AKShare 接口丰富但稳定性差，适合作为数据获取的辅助层，不应作为唯一数据源。** 本项目已对部分接口（如 `stock_news_em`）改用直接 HTTP 请求，这是正确策略。

## 4. BaoStock

### 可用性：稳定，完全免费，数据偏基本面和回测

#### 概况

- **完全免费**，无需注册，无需 token
- 提供A股K线、基本面、宏观数据
- 接口稳定，适合个人量化研究

#### 数据类型

| 数据类型 | 是否支持 | 说明 |
|---------|---------|------|
| 日K/周K/月K | 是 | 历史K线，前复权/后复权 |
| 分钟K线 | 是 | 5/15/30/60分钟 |
| 实时行情 | 有限 | 非逐笔，更新频率低 |
| 财务数据 | 是 | 季度报表、盈利能力等 |
| 宏观经济 | 是 | GDP/CPI/PMI 等 |
| 分时/盘口 | 否 | — |
| 资金流向 | 否 | — |
| 资讯 | 否 | — |
| 量比 | 否 | — |
| 52周高低 | 否 | 需从K线自行计算 |

#### 限制

- 数据更新频率有限，非实时
- 部分高级数据缺失（盘口、资金流向、资讯）
- 维护活跃度一般，近年代码更新较少

#### 结论

**适合历史K线和基本面数据回测，不适合实时行情场景。** 本项目以实时行情为主，BaoStock 价值有限。

## 5. Tushare 免费额度

### 可用性：积分制，注册送基础积分，高级接口需积分

#### 免费额度

- 注册即获基础积分（约 120 分）
- 免费积分可获取：日线行情、财务数据、指数数据等基础数据
- 提升积分方式：邀请注册、捐赠（200元=2000积分）、社区贡献

#### 积分与接口对应

| 积分门槛 | 可用接口 |
|---------|---------|
| 0-120（免费注册） | 日线/周线/月线、基础财务、指数、行业分类 |
| 120-2000 | 分钟线、复权因子、沪深股通 |
| 2000+ | Level-2 行情、龙虎榜、融资融券、更细粒度财务 |
| 5000+ | 几乎全量数据 |

#### 限制

- 免费积分接口覆盖有限，实时行情需较高积分
- 每分钟调用次数按积分等级限制（免费约 200次/分钟）
- 数据延迟：免费层级行情延迟约 15 分钟
- 高频实时场景不适用

#### 结论

**免费额度适合基础研究和回测，实时行情需要较高积分。** 对本项目（实时模拟交易），免费额度不够用。

## 6. 东方财富直接 API (East Money Direct)

### 可用性：可直接调用，数据最全，需自行维护参数

东方财富是 AKShare `_em` 后缀接口的底层数据源。绕过 AKShare 直接调用，可更快响应源站变更。

#### 已知端点

| 端点 | 说明 |
|------|------|
| `https://push2.eastmoney.com/api/qt/clist/get` | 全市场实时行情（含量比、换手率等），分页获取 |
| `https://push2his.eastmoney.com/api/qt/stock/kline/get` | 历史K线（日/周/月/分钟） |
| `https://push2.eastmoney.com/api/qt/stock/get` | 个股详情（量比、52周高低、市盈率等） |
| `https://push2.eastmoney.com/api/qt/stock/trends2/get` | 分时成交数据 |
| `https://datacenter-web.eastmoney.com/api/data/v1/get` | 资金流向、龙虎榜等 |
| `https://search-api-web.eastmoney.com/search/jsonp` | 资讯搜索 |

#### 全市场行情端点参数示例

```
https://push2.eastmoney.com/api/qt/clist/get?
  pn=1                    # 页码
  pz=80                   # 每页条数
  po=1                    # 排序方向
  np=1                    # 不分页
  fltt=2                  # 浮点精度
  invt=2                  # 不含ETF
  fid=f3                  # 排序字段（f3=涨跌幅）
  fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23  # 市场筛选
  fields=f2,f3,f4,f5,f6,f7,f8,f9,f10,f12,f14,f15,f16,f17,f18,f20,f21,f23,f24,f25,f115
```

#### 关键字段 (fields 参数)

| 字段 | 说明 | 字段 | 说明 |
|------|------|------|------|
| f2 | 最新价 | f12 | 股票代码 |
| f3 | 涨跌幅 | f14 | 股票名称 |
| f5 | 涨跌额 | f15 | 最高价 |
| f6 | 成交量 | f16 | 最低价 |
| f7 | 成交额 | f17 | 今开 |
| f8 | 换手率 | f18 | 昨收 |
| f9 | 市盈率 | f10 | 量比 |
| f20 | 总市值 | f21 | 流通市值 |
| f23 | 市净率 | f115 | 市盈率(静) |

#### 优势

- **数据最全**：实时行情含量比、52周高低、资金流向、分时、K线一站齐备
- **无第三方依赖**：直接 HTTP 调用，AKShare 断裂时可直接切换
- **响应速度快**：无需等待 AKShare 发版修复

#### 风险与限制

- 接口无官方文档，字段编号可能变更
- 反爬机制：高频请求可能触发验证码或 IP 封禁
- 建议请求间隔 >= 2 秒
- 需要自行维护请求参数和字段映射

#### 结论

**直接调用东方财富 API 是当前最实用的策略。** 本项目已有部分接口（如资讯）改用直接 HTTP 请求，建议对更多 `_em` 后缀接口做同样迁移。

## 综合对比

| 数据源 | 实时行情 | K线 | 分时 | 盘口 | 资金流向 | 财务 | 资讯 | 稳定性 | 免费 |
|--------|---------|-----|------|------|---------|------|------|--------|------|
| 新浪财经 | 是 | 是 | 否 | 否 | 否 | 否 | 否 | 低 | 是 |
| 腾讯财经 | 是 | 是 | 否 | 否 | 否 | 否 | 否 | 中 | 是 |
| AKShare | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 低-中 | 是 |
| BaoStock | 有限 | 是 | 否 | 否 | 否 | 是 | 否 | 高 | 是 |
| Tushare | 延迟 | 是 | 需积分 | 否 | 需积分 | 是 | 否 | 高 | 积分制 |
| 东方财富直调 | 是 | 是 | 是 | 否 | 是 | 有限 | 是 | 中 | 是 |

## 对本项目的建议

1. **新浪+腾讯双源回退**（当前策略）→ 保持，这是正确的基础架构
2. **逐步将 AKShare `_em` 接口替换为东方财富直接 API**：本项目已对 `stock_news_em` 完成替换，建议继续迁移 `stock_intraday_em`、`stock_bid_ask_em`、`stock_individual_fund_flow`、`stock_zh_a_minute`
3. **财务数据**：`stock_financial_abstract_ths`（同花顺源）相对稳定，可暂保留 AKShare 方式
4. **AKShare 作为降级**：保留 AKShare 调用作为直接 API 的 fallback，而非主路径
5. **BaoStock** 可作为历史K线的备用源，当新浪/腾讯K线接口异常时切换
6. **Tushare** 免费额度对本项目实时场景价值有限，暂不建议引入
